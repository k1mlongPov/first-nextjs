- JSX = Javascript XML/HTML:
  1. write javascript inside xml/html ({})
  2. Rule Naming Convention (Pascal Case) : e.g. ProductCard
  3. One-way Data Binding ( parent -> children)
  4. Cannot use if/else condition in JSX rule instead JSX uses ternary expression
     condition ? expression_if_true : expression_if_false;
  5. return only one Root element
  6. called component using close all tag: e.g. <Card/>
